## 3. Грабли, на которые уже наступили (не наступать снова)

1. **Кэш.** У `anim3.js` в адресе стоит версия `?v=N`. **При любой правке anim3.js версию поднять**, иначе браузер отдаёт старый файл и правка выглядит несделанной.
2. **Размер канваса трубок.** Библиотека берёт размер от родителя. Родитель обязан быть фиксированным слоем в экран (`#tubelayer`), иначе канвас растянется на всю длину страницы (было 849×6933) и машина ляжет.
3. **Наложение `mix-blend-mode`** должно стоять на слое-обёртке, а не на канвасе: фиксированный элемент создаёт свой контекст наложения, и канвас закрасит звёзды чёрным.
4. **`.beam{position:relative}`** перебивает `.proj{position:absolute}` при равной силе — правилам веера нужен родительский селектор `.projects .proj`.
5. **Сокращённое `background:` у карточки** убивает картинку прожектора: правило `.glow` должно быть сильнее.
6. **`background-attachment:fixed` не работает внутри повёрнутых элементов** — прожектор считается в координатах самой карточки через `--ox/--oy`.
7. **`100vw` учитывает полосу прокрутки** и даёт боковую прокрутку. У `body` стоит `overflow-x:hidden`, полноширинные приёмы не использовать.
8. **Морф пишет первые слова при создании**, а не в первом кадре — иначе на телефоне пустой слоган.
9. **Звёзды рисуются тремя вызовами** (группировка по толщине). Не возвращать отрисовку по одной звезде.
10. **Одна область видимости у сцены трубок.** Переменные `app/cv/k/sp/p0` и цикл цвета обязаны жить в одном месте, иначе цикл падает каждый кадр и цвет замирает.
11. **Удаляя секцию, проверить её стили** — однажды вместе с разделителем вырезался блок стилей карточек, лежавший между двумя кусками.

## 4. Телефон

- 3D-сцена не запускается совсем (определяется по типу указателя, не по ширине).
- Морф работает в лёгком режиме: перекрёстное затухание без SVG-фильтра и размытия.
- Звёзды: 120 штук, ограничение 30 кадров в секунду.
- Меню под бургером, все цели для пальца не меньше 44 пикселей.
- Дальние секции не считаются, пока не приблизятся к экрану.

## 5. Порядок деплоя

```bash
node --check anim3.js && node --check win.js      # синтаксис
# поднять ?v=N у anim3.js, если он менялся
git add -A && git commit -m "..." && git push
# дождаться, пока curl увидит правку на solutions101.net
```

Проверять после деплоя: слоган не пустой, ленты только у текста, боковой прокрутки нет, карточки не переполняются, ассистент открывается окном и страница остаётся кликабельной.
